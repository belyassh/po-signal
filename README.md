# PO Signal — версия для Cloudflare

Веб-приложение для телефона: посекундный график Pocket Option, выбор любой пары и кнопка
**АНАЛИЗ**, которая выдаёт подсказку **ЛОНГ (вверх)**, **ШОРТ (вниз)** или **нет сигнала**.
Каждый сигнал сам проверяется по цене на экспирации, а бэктест показывает,
угадывает ли алгоритм чаще порога безубыточности.

Приложение **только читает котировки**. Сделки оно не открывает.

## Как это устроено на Cloudflare

```
Телефон ⇄ Worker (пароль, интерфейс) ⇄ Durable Object «PoFeed» ⇄ Pocket Option
                                           └─ SQLite: история за 6 часов
```

- **Worker** отдаёт интерфейс из папки `public/`, проверяет пароль и пересылает запросы в Durable Object.
- **Durable Object** — один на всё приложение. Он держит WebSocket-соединение с Pocket Option,
  копит котировки и раз в минуту сохраняет их в SQLite, поэтому история переживает деплои и перезапуски.
  Cron раз в минуту проверяет, что он жив.
- **Анализ, проверка сигналов и бэктест** считаются прямо в телефоне (`public/analysis.js`).
  Так сервер укладывается в лимиты бесплатного тарифа по процессорному времени.

Всё работает на **бесплатном тарифе Workers**, карта не нужна.

## 1. Залить в GitHub

Создай **приватный** репозиторий, например `po-signal`, и загрузи туда содержимое этой папки:

```bash
cd po-signal-cf
git init && git add . && git commit -m "PO Signal (Cloudflare)"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/po-signal.git
git push -u origin main
```

## 2. Подключить к Cloudflare (деплой из GitHub)

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Import a repository**.
2. Выбери репозиторий `po-signal`. Команда деплоя по умолчанию `npx wrangler deploy` подходит,
   корневая папка — корень репозитория.
3. **Deploy**. Через минуту появится адрес вида `https://po-signal.ТВОЙ-ПОДДОМЕН.workers.dev`.
4. Открой воркер → **Settings → Variables and Secrets** → **Add** → тип **Secret**:
   - `APP_PASSWORD` — пароль на вход. **Обязательно:** адрес открыт всему интернету.
   - `SSID` — строка `42["auth",{...}]`, необязательно. Её можно вставить и с телефона в ⚙︎ Настройках.
5. После сохранения секретов Cloudflare сам перезапустит воркер.

Дальше каждый `git push` в `main` автоматически обновляет приложение.
Свой домен из Cloudflare можно привязать в **Settings → Domains & Routes**.

## 3. Поставить на телефон

Открой адрес и войди по паролю.

- **iPhone (Safari):** «Поделиться» → «На экран “Домой”»
- **Android (Chrome):** ⋮ → «Установить приложение» / «Добавить на главный экран»

## 4. SSID — где взять

SSID берётся на **компьютере**:

1. Зайди на pocketoption.com и открой **демо-счёт** (приложению нужны только котировки).
2. F12 → **Network** → фильтр **WS** → обнови страницу.
3. Кликни websocket-соединение → **Messages** → строка, которая начинается с `42["auth",`.
4. Скопируй её **целиком** и вставь в приложении: ⚙︎ → «Сохранить SSID» (или в секрет `SSID`).

SSID, сохранённый из приложения, хранится в Durable Object и переживает перезапуски.
Он действует, пока ты не поменяешь секрет `SSID` в панели: тогда главным снова становится секрет.
Если Pocket Option отклонит SSID, в строке статуса появится «SSID устарел — вставь новый».

> ⚠️ SSID — это доступ к твоему аккаунту, как пароль. Не коммить его в GitHub.

## 5. Пользоваться

- **Пара:** нажми на название вверху. Есть поиск, категории, избранное ☆ и выплаты из Pocket Option.
- **График:** 1м / 3м / 5м / 15м / 30м. Если провести пальцем по графику, видно время и цену.
- **Экспирация + АНАЛИЗ:** внизу экрана. Ниже графика появится вердикт и разбор четырёх индикаторов.
- **Мои сигналы:** хранятся в телефоне и сами проверяются через выбранную экспирацию.
- **Бэктест:** прогоняет алгоритм по истории пары за последние 6 часов, которая хранится на сервере.
- **Выплата:** берётся из Pocket Option, вручную можно поправить в ⚙︎.

### Безубыток

При выплате `P` нужно угадывать больше `1 / (1 + P)` сделок:
92% → 52,1%, 80% → 55,6%, 50% → 66,7%, 28% → 78,1%.
Если в бэктесте процент попаданий не выше этого порога, совет на дистанции теряет деньги.

## Бесплатные лимиты Cloudflare

| Что | Бесплатно в день | Сколько тратит приложение |
|---|---|---|
| Durable Objects, время работы | 13 000 GB-s | ~11 000 GB-s при работе 24/7 (объект занимает 128 МБ) |
| Durable Objects, запросы | 100 000 | ~2 400 в час, пока приложение открыто, + ~4 300 служебных (будильник и cron) |
| Workers, запросы | 100 000 | столько же, сколько опросов из приложения |
| SQLite, записи строк | 100 000 | ~3 000 (одна строка в минуту + очистка) |

Если в аккаунте есть другие Durable Objects и квоты на время не хватает, поставь переменную
`IDLE_MINUTES` = `20`. Тогда соединение с Pocket Option будет засыпать через 20 минут после
последнего открытия приложения и просыпаться при следующем заходе. История в это время не копится.
На платном Workers ($5 в месяц) ограничений практически нет.

## Настройки (Variables)

| Переменная | Что это | По умолчанию |
|---|---|---|
| `APP_PASSWORD` (secret) | пароль на вход; нужен и для смены SSID из приложения | — |
| `SSID` (secret) | `42["auth",{...}]` | — |
| `ASSET` | пара при первом запуске | `SOL-USD_otc` |
| `PERIOD` | period подписки `changeSymbol`. Если котировки не идут, попробуй `5` | `60` |
| `IDLE_MINUTES` | засыпать без зрителей (0 — работать всегда) | `0` |
| `DEMO` | `1` — симуляция без Pocket Option | `0` |

Обычные переменные меняются в `wrangler.jsonc` (раздел `vars`) и уходят на Cloudflare при деплое.

## Запуск на своём компьютере

```bash
cp .dev.vars.example .dev.vars        # впиши пароль и SSID
npx wrangler dev                      # http://localhost:8787
```

## Если что-то не работает

- **«Не удалось открыть соединение» / «Сервер Pocket Option не ответил»** — возможно, Pocket Option
  не пускает подключения из сети Cloudflare. Проверь логи: Workers → po-signal → **Logs**.
  Запасной вариант — Python-версия на своём компьютере, открытая наружу через Cloudflare Tunnel.
- **«Pocket Option отклонил SSID»** — вставь свежий SSID.
- **«Нет котировок … пара закрыта или неверное название»** — выбери другую пару или поставь `PERIOD` = `5`.
- Протокол взят из неофициальной библиотеки PocketOptionAPI, которую автор больше не развивает.
  Если Pocket Option его поменяет, подключение сломается. Использование неофициального API
  может нарушать правила брокера.

## Файлы

- `src/worker.js` — вход: пароль, статика, маршрутизация, cron
- `src/feed-do.js` — Durable Object: соединение, история в SQLite, API котировок
- `src/core.js` — протокол Pocket Option, разбор котировок и списка пар, симуляция
- `src/assets_fallback.json` — запасной список пар
- `public/` — интерфейс (`index.html`), алгоритм (`analysis.js`), иконки и манифест
- `wrangler.jsonc` — настройки Cloudflare
